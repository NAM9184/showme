🌐 개인 랜딩페이지 (Next.js + TypeScript + Module CSS)
👋 개인 랜딩페이지 프로젝트입니다.
Next.js, TypeScript, Module CSS를 활용하여 빠르고 최적화된 개인 소개 웹사이트를 제작진행중입니다.

🚀 프로젝트 개요
이 프로젝트는 개인 프로필, 포트폴리오, 연락처 정보를 전달하는 랜딩페이지입니다.

📌 주요 기능
Next.js 기반 정적 페이지 생성(SSG) & 동적 렌더링(SSR)
TypeScript를 사용한 안정적인 코드 작성
Module CSS를 활용한 컴포넌트별 스타일링
반응형 디자인 적용 (모바일, 태블릿, 데스크탑 대응)
SEO 최적화 (메타 태그, Open Graph 설정)
Dark/Light Mode 지원 (작업예정사항)
